# Guía de Contribución

¡Gracias por tu interés en contribuir! Aquí están las directrices para ayudarte.

## Cómo contribuir

### Reportar bugs

1. Verifica que el bug no haya sido reportado ya
2. Si no existe, abre un issue con:
   - Descripción clara del problema
   - Pasos para reproducir
   - Comportamiento actual y esperado
   - Tu entorno (SO, versión de Python, etc.)

### Sugerir mejoras

1. Usa el mismo proceso que para reportar bugs
2. Describe claramente la mejora sugerida
3. Proporciona ejemplos de cómo debería funcionar

### Pull Requests

1. Fork el proyecto
2. Crea una rama para tu feature (`git checkout -b feature/AmazingFeature`)
3. Commit tus cambios (`git commit -m 'Add some AmazingFeature'`)
4. Push a la rama (`git push origin feature/AmazingFeature`)
5. Abre un Pull Request

### Estilo de código

- Sigue PEP 8
- Usa nombres descriptivos para variables y funciones
- Comenta código complejo
- Documenta funciones con docstrings

### Pruebas

- Prueba tu código localmente antes de hacer push
- Verifica que no rompas funcionalidad existente

## Preguntas

Si tienes preguntas, abre un issue con la etiqueta `question`.

¡Esperamos tus contribuciones!
